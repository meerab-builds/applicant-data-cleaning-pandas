# 📊 Applicant Data Cleaning & Exploration

A beginner-friendly data analytics project completed as part of the **NextGen Learners Data Science Internship — Week 1**.

## 🎯 Project Overview

This project focuses on cleaning and exploring an applicant dataset using Python and Pandas to improve data quality and consistency.

## 🛠️ Tools Used

- Python
- Pandas
- Jupyter Notebook

## 🧹 Data Cleaning Process

- Explored the dataset and identified missing values
- Handled missing records
- Removed duplicate rows and duplicate email records
- Standardized text and application domain categories
- Cleaned date and phone number formats
- Verified the final dataset

## 📁 Project Files

| File | Description |
|---|---|
| `Week1_Data_Cleaning_Meerab.ipynb` | Notebook containing the cleaning process and explanations |
| `applicants_cleaned.csv` | Exported cleaned dataset |

## 📌 Outcome

The project provided practical experience in data preprocessing, data quality checks, and preparing structured data for further analysis.
